# 강호 설계 규범집

무협 세계관을 빠르게 구축하기 위해 지역 설계와 캐릭터 설계를 절차화한 가이드입니다. 아래 규칙에 따라 요소를 채워 넣으면, 이미 정리해 둔 세계관 자료와 자연스럽게 맞물리도록 설계할 수 있습니다.

## 1. 사용 개요
- 본문은 `세계관 - 무협 (Wuxia).md`에 정리된 규칙을 압축 요약한 것입니다.
- "지역 설계 플로우"와 "캐릭터 생성 플로우"를 각각 반복 적용하면, 새 사건이 추가될 때마다 모순 검사를 자동화할 수 있습니다.
- 설계 결과는 연대표·미션 시트·로그라인과 연동해 기록하세요.

---

## 2. 지역 설계 마스터 플로우

### 2.1 하향식(Top-down) 4단계
1. **1차 앵커 선언** — 대륙/권역별 기후, 통치 세력, 문화 코드를 고정합니다. *(예: 황도권 = 황실 감찰, 초원권 = 자치권 투쟁)*
2. **2차 기능 벨트 배치** — 정치·경제·수련·은신 등 기능 구역을 도식화해 사건 분배 틀을 만듭니다.
3. **3차 대표 거점 정의** — 각 벨트마다 대표 도시 1~2곳과 핵심 갈등·상징물을 지정합니다.
4. **가이드라인 문장화** — "황도권에는 감찰국 감시가 항상 존재한다"처럼 불변 규칙을 문장으로 남깁니다.

### 2.2 상향식(Bottom-up) 3단계
1. **포켓 씬 작성** — 필요한 장소(사원·골목·수로)를 먼저 만들고 관리 세력·자원 메모를 붙입니다.
2. **스폿 묶음 → 구역 승격** — 테마가 비슷한 장소 3~4개를 묶어 구역으로 명명하고 공통 갈등을 정의합니다.
3. **메타데이터 표기** — 각 장소에 `소속/세력/자원/금기` 태그를 달아 상위 구조에 편입될 준비를 합니다.

### 2.3 작은 설정을 품는 구조 예시
| 구조 | 설명 | 적용 포인트 |
| --- | --- | --- |
| 속주 → 현 → 세트 | 속주가 행정·자원·갈등 핵심을 저장, 현은 주민 문화, 세트는 장면 연출 담당 | 속주에 고정 규칙을 기록하면 하위 요소가 상치되지 않음 |
| 허브-레이어 | 허브(황도)와 주변 레이어(야시장, 수로 등)를 정의 후 소거점을 레이어에 추가 | 허브만 유지하면 레이어가 늘어나도 중심 톤이 일관 |
| 축/노선 그리드 | 거상로·대장벽 같은 선형 축을 먼저 설정하고 축 위에 거점 배치 | "축에는 역참+표국 쌍 존재" 등의 규칙으로 모순 최소화 |

### 2.4 모순 최소화 체크리스트
1. **앵커 리스트** — 권역별 변하지 않는 사실 5가지를 만든다.
2. **충돌 매트릭스** — 새 장소의 자원·세력·금기를 앵커와 대조한다.
3. **교통/시간 계산** — 기존 이동 노선에 거리·시간을 적어 둔다.
4. **정보 흐름 시뮬레이션** — 소문·통신이 규칙에 맞게 퍼지는지 점검한다.

### 2.5 실전 적용 루틴
- Step A: 사건이 필요한 작은 세트를 설계하고 담당 세력·자원을 기록한다.
- Step B: 세트를 품을 구역(현/레이어)을 지정, 상위 규칙과 금기를 덧입힌다.
- Step C: 구역을 전체 지도/축/허브 구조에 배치하며 연결선을 추가한다.
- Step D: 앵커·충돌·교통·정보 점검 후, 연대표·미션 시트에 영향 메모를 남긴다.

## 3. 캐릭터 생성 플로우

### 3.1 체크리스트 레이어
| 레이어 | 질문 | 기록 예시 |
| --- | --- | --- |
| 정체성 | 어디 출신이며 어떤 조직과 연이 있는가? | 황도 수로 출신, 비운루 사제, 천명파와 동맹 |
| 능력 | 내공/외공 비율, 대표 무공·무기, 비전 지식은? | 내공 70·외공 30, 청명선 부채, 기류 제어 |
| 정서 | 의리·원한·트라우마·신념은? | 강호 삼금 수호, 부모 실종 원한 |
| 관계 | 스승·동료·경쟁자·민중과 관계는? | 강정무(스승), 설하윤(정보 협력), 장무린(대립) |
| 시각 | 의복·소품·상처·움직임은? | 청자색 도포, 은전 목걸이, 빠른 보폭 |

### 3.2 아키타입 템플릿
| 템플릿 | 핵심 특징 | 차별화 장치 |
| --- | --- | --- |
| 강호 중재자 | 문파 + 상단 교섭, 내공 방어 위주 | 서찰·인장 소품, 협상 실패 시 감정 폭발 |
| 은신 암살자 | 수로·암기 특화, 감정 절제 | 감각 묘사(발자국·향), 금기 존중 반전 |
| 기술 협객 | 공학·의술 등 비무공 기술, 함정 전투 | 장비 제작 묘사, 실험 흔적 상처 |

### 3.3 묘사 문장 틀
1. **동작 + 감각** — "청명운이 청명선을 펼치자 청자색 섬광이 수로 벽을 훑었다."
2. **관계 반응** — "강정무가 팔문진을 가동하자 청명운은 스승 숨소리에 맞춰 호흡을 조절했다."
3. **내적 갈등** — "은전 목걸이를 쥔 순간, 그는 강호 삼금이 무너지는 장면을 떠올렸다."

### 3.4 메인-서브 동시 설계 팁
- 보드 한 장에 메인 캐릭터와 서브 캐릭터를 나란히 배치하고 체크리스트 항목을 미러링한다.
- 관계 레이어에 `갈등/동맹/의존` 세 가지 축을 동시에 채워 서로를 보완하거나 대조할 지점을 확보한다.
- 새 서브 캐릭터를 만들 때는 "누구의 앵커를 흔드는가?"를 먼저 정의하면 플롯 연결이 쉬워진다.

### 3.5 빠른 확장 기법
- **카드 조합법** — (출신지)+(주무공)+(금기)+(상징 소품)을 랜덤 조합해 후보 생성.
- **사건 역추적** — 연대표·미션 시트 빈칸에 "누가 관여했을까?"를 질문해 캐릭터를 끼워 넣는다.
- **성장 단계 지정** — 입문/연공/파경/천극 중 위치를 정해 말투·태도를 결정한다.

- 통치 세력:
- 불변 규칙(앵커) 5가지:

- 기능(정치/경제/수련/은신):

- 대표 상징물:
- 인접 레이어: (예: 야시장, 수로, 사제 구역)

[세트 씬] (허브 레이어 안의 구체 공간)

## 5. 실전 운영 루틴 (요약)
1. 사건이 필요하면 **세트 씬**을 만들고 담당 세력·자원을 메모한다.
2. 세트가 소속될 **허브/속주**를 지정하고 앵커 규칙과 금기를 재확인한다.
3. 전체 지도와 **축/노선**에 연결선을 추가해 이동·정보 흐름을 검증한다.
4. **모순 체크리스트**와 **캐릭터 체크리스트**를 돌려 연대표·로그라인에 반영한다.

이 규범집을 따라 요소를 채워 넣으면, 작은 설정을 추가해도 상위 구조와 자연스럽게 맞물리고 캐릭터 간 갈등 축이 명확해집니다.

### 적용 예시 — 청명운 & 황도 수로
```markdown
[속주 이름]
- 기후/자원: 황도 속주 / 온난 습윤, 황하 수운, 비단·정보망
- 통치 세력: 황도 감찰국, 천명파 연합 의회, 거상로 상단 중계처
- 불변 규칙(앵커) 5가지:
  1. 황도권에는 감찰국 감시가 상시 존재한다.
  2. 수로 네트워크는 상단·문파·황실이 공동 관리하지만 비밀 경로가 얽혀 있다.
  3. 황도 야시장은 정보·의뢰·부적 거래의 허브이며 등롱 암호 규약을 따른다.
  4. 황도 속주의 운하는 전면 봉쇄 시 경제·정치가 즉시 마비된다.
  5. 황실 사면령은 전쟁 직전 수로와 문파의 통제권을 재조정한다.

[허브 이름] (속주 내 중심 도시)
- 기능: 정치/은신 허브 (황도 코어 & 지하 수로)
- 핵심 갈등: 감찰국 숙청 vs 문파 자치, 상단 자금줄의 배분
- 대표 상징물: 청명선 수로 거울, 황도 비밀경 인장, 야시장 등롱표
- 인접 레이어: 황도 코어 행정 지구, 지하 수로 네트워크, 야시장·부적 상점, 사자후 언론 구역

[세트 씬] 황도 수로 잠입로
- 장면 목적: 감찰국 비밀 서고에 잠입해 숙청 명단 확보
- 등장 세력: 청명운·비운루, 황도 감찰국, 천명파 지원조, 설하윤 정보상
- 갈등·장애물: 감찰국 감시망, 수로 봉쇄 문, 이중 암호
- 감각 키워드: 청자 섬광, 물비린 향, 등롱 반사
```

### 캐릭터 시트 — 청명운 / 설하윤
| 레이어 | 청명운 | 설하윤 |
| --- | --- | --- |
| 정체성 | 황도 수로 출신 천명파 청년조 | 거상로 상단 정보상, 황도 파견사 |
| 능력 | 내공 70·외공 30, 청명선 기류 제어, 은신 보법 | 위조 문서, 인장술, 암호 해독, 네트워크 구축 |
| 정서 | 강호 삼금 수호, 부모 실종 원한, 폭력 난조 거부 | 상단 중립 유지, 개인적 생존과 의리 사이 갈등 |
| 관계 | 강정무(스승), 설하윤(정보 협력), 장무린(대립) | 청명운(협력자), 상단 중립파(상관), 감찰국 내 스파이(암거래) |
| 시각 | 청자색 도포, 은전 목걸이, 청명선 부채 | 비단 상인복, 코드 목걸이, 문서 인장 세트 |

- **메모**: 설하윤은 상단 내 친황파와 중립파 사이에서 줄타기하며, 청명운의 수로 잠입 작전에 정보·위조 문서를 제공한다. 갈등 시점에서 상단 자금줄의 방향을 바꿀 수 있는 인물이다.
