# 여정 서사 설계 규범집

## 1. 사용 개요
- 순례·구법·성소 정화가 중심인 여행 서사를 설계할 때 적용한다.
- 성지, 오아시스, 의회를 잇는 이동 구조와 시험-계시-성장의 리듬을 유지한다.

## 2. 여정 구조 플로우
### 2.1 앵커
- **성지(사원/아슈라마)**: 시련 관문, 정화 의식, 계시를 담당.
- **오아시스 도시**: 교역, 보급, 정보 중계.
- **의회/의식 장소**: 교단 논쟁, 공동체 판단.

### 2.2 절차
1. 지도에 순례 루트(사막, 산맥, 강)를 그리고 각 구간에 성지/오아시스를 배치한다.
2. 성지마다 시련 조건(참회, 희생, 정화)을 작성한다.
3. 오아시스에는 보급 품목, 중립 규약, 갈등 원인을 지정한다.
4. 의회 장면을 통해 여정의 의미·보상을 재정의한다.

### 2.3 모듈 팁
- **관문 모듈**: 실패 시 감정·신앙 흔들림, 성공 시 계시 제공.
- **오아시스 봉쇄**: 도적/정치 갈등, 협상가/전사/수도승 역할 배분.
- **의회 모듈**: 기록 공개, 예언서, 투표 절차.

## 3. 캐릭터 설계 플로우
### 3.1 체크 포인트
- **역할**: 순례 인도자, 후원자, 수행자, 기록관, 전사 등.
- **신념**: 개인 구원 vs 공동 사명 중 어느 쪽에 무게를 두는가?
- **속죄/과거**: 시련에서 고백하거나 넘어서야 할 과오는 무엇인가?
- **능력**: 의식 수행, 협상, 전투, 기록, 치유 중 핵심 2개.
- **상징물**: 순례 지팡이, 사원 인장, 의례 물, 예언서 등.

### 3.2 아키타입 예시
- **라마(인도자)**: 경로 지식, 신앙 지휘.
- **귀족 후원자**: 외교·재정 지원, 조건 제시.
- **청지기/수행 소년**: 순수함, 숨겨진 죄.
- **협상 전사**: 전투와 외교를 병행.

## 4. 운용 루틴
1. 여정 단계마다 "시련-정화-계시" 체크리스트를 적용한다.
2. 캐릭터의 신념이 충돌할 장면을 오아시스/의회에 배치한다.
3. 새 성소나 사건이 추가되면 순례 루트 지도와 의회 기록을 동시에 갱신한다.
