# 하이 판타지 자료집

## 1. 기초 참고 자료
- J.R.R. 톨킨 *반지의 제왕* — 다종족 연합, 언어·신화 창조.
- Ursula K. Le Guin *Earthsea* — 이름의 마법, 제자-스승 성장 서사.
- Brandon Sanderson *Mistborn* — 금속 기반 마법 시스템과 반란 구조.

## 2. 심화 리서치 포인트
- **중세 정치·경제**: Marc Bloch *Feudal Society*, 조지 뒤비 *중세의 경제와 사회*.
- **마법 시스템 이론**: Brandon Sanderson “Three Laws of Magic”, RPG 룰북(D&D 5e, Pathfinder).
- **지도 제작**: Cartographers’ Guild 튜토리얼, Azgaar’s Fantasy Map Generator 사용법.

## 3. 참고 미디어
- 넷플릭스 *위쳐* 시리즈 — 괴물 사냥꾼과 정치 음모.
- 게임 *Dragon Age: Origins* — 다문화 동맹, 앙티바의 정치 구조.
- 웹소설 *템빨* — 현대 지식을 이용해 판타지 세계 재건.

## 4. 설정 체크리스트
- 대륙 지도(제국/연맹/방어선)
- 마력 결절(돌원, 성소) 목록과 기능
- 봉건제 작위, 기사단 조직, 교단 서열
- 언어·문화별 인사말, 의상, 음식
