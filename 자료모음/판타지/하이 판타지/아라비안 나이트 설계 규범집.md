# 아라비안 나이트 설계 규범집

## 1. 사용 개요
- 항구, 시장, 사막 카라반, 궁정 야화가 얽힌 중동·페르시아풍 서사를 설계할 때 활용한다.
- `세계관 - 아라비안 나이트 (Arabian Nights).md`의 허브(항구/궁정/카라반) 데이터를 요약했다.

## 2. 지역 설계 플로우
### 2.1 앵커
- **항구 도시**: 만국 시장, 항로 길드, 별자리 지도.
- **카라반사라이**: 사막 정령과의 서약, 대상단 휴식·정보 교환.
- **궁정/향료 궁정**: 권력, 이야기, 지식의 보관소.
- 지명은 `Al-`, `Dar al-`, `-shahr`, `-abad` 등을 조합한다.

### 2.2 절차
1. 항구-카라반-궁정 삼각 동선을 정의한다.
2. 각 거점에 상업(향료/보물), 신화적 존재, 궁정 정치 요소를 최소 하나 배치한다.
3. 이동 시 별자리/바람/향료 같은 감각 안내자를 설정한다.
4. 새로운 도시를 추가하면 "어떤 전설 or 서약"을 품고 있는지 서술한다.

### 2.3 모듈 팁
- **항해 모듈**: 별 지도, 항해사, 해적/정령을 세트로 설계.
- **카라반 서약**: 폭풍, 정령 협약, 궁정 밀사 갈등을 패키지화.
- **향료 재판**: 길드 vs 궁정, 시 낭독/품평을 사건 장치로 사용.

## 3. 캐릭터 설계 플로우
### 3.1 체크 포인트
- **정체성**: 상인, 항해사, 정령 통역자, 시인, 궁정 첩보 등.
- **경로**: 항로/사막로/궁정 어느 허브를 기반으로 움직이나?
- **계약/서약**: 정령, 궁정, 길드 중 누구와 어떤 약속을 맺었는가?
- **소품**: 향료 상자, 별 지도, 서사 두루마리 등.
- **이야기 자산**: 누구의 야화를 전하거나 수집하는가?

### 3.2 아키타입 예시
- **별자리 상인**: 지식 도서관을 찾는 항해자.
- **정령 통역자**: 인간-정령 조약을 유지.
- **궁정 시인/재판관**: 이야기로 진실을 판정.
- **카라반장**: 대상단 보호, 궁정과 시장 사이 협상.

## 4. 운용 루틴
1. 사건 설계 시 향료·별·바람 중 하나를 감각 장치로 사용한다.
2. 캐릭터의 서약/이야기 자산을 대비시켜 서사 갈등을 만든다.
3. 새 거점을 추가하면 항구/사막/궁정 어느 허브에 속하는지 명확히 기록한다.
