# 현대 로맨스 샘플 아이디어

1. **“퇴근 후 동아리”**
   - 배경: 서울 강남 IT 기업 / 사내 밴드 동호회
   - 갈등: 팀장-신입 간 권력 거리 vs 음악으로 연결되는 공감
   - 포인트: 라이브 공연, 야근 문화, 익명 SNS 커뮤니티

2. **“카페 로테이션”**
   - 배경: 공유 오피스 건물 1층 카페
   - 갈등: 창업자와 바리스타의 상권 갈등 → 협업 로스터리 프로젝트
   - 포인트: 커피 블렌딩, 수제 디저트, 고객 후기 플랫폼

3. **“거리의 구독자”**
   - 배경: 유튜브 맛집 채널 + 정책 연구원
   - 갈등: 온라인 노출을 꺼리는 공무원 vs 구독자를 늘리려는 크리에이터
   - 포인트: 촬영 일정, 댓글 반응, 공공 데이터 활용
