# 스페이스 오페라 설계 규범집

## 1. 사용 개요
- 항성 실크웨이, 워프 게이트, 궤도 도시를 중심으로 한 대규모 우주 문명을 설계할 때 적용한다.
- `세계관 - SF·스페이스 오페라.md`의 세부 데이터를 요약한 규칙으로, 노드/허브/조차지 구조를 빠르게 만들 수 있다.

## 2. 우주 거점 설계 플로우
### 2.1 상위 앵커
- **항성 실크웨이 노드**: 모든 거점은 "에너지 공급·교역 품목·지정 군사권"을 갖는다.
- **허브 계층**: `Prime`(정치) → `Core`(행정) → `Orbital`(주거) 레이어를 유지한다.
- **조차지 규약**: 토착 정부·황실·기업 3자 관계를 항상 명시한다.

### 2.2 절차
1. 워프 허브 위치와 자원(에너지/정보/문화)을 선언한다.
2. 허브에 부속된 궤도/지상 구역을 구분하고 중력·환경 제약을 설정한다.
3. 노드 간 연결선에 "통행 규약"과 "위기 시 차단 조건"을 기입한다.
4. 노드가 늘어날 때는 `Gate 이름 + 코드` 규칙을 따르고, 기존 노선에 교차점을 추가한다.

### 2.3 모듈 팁
- **링월드 모듈**: 섹터별 행정/기압/문화 테마를 정하고 정기 순환 이벤트를 배치한다.
- **프론티어 모듈**: 자원 쿼터, 토착 계약, 용병 면허 3 요소를 고정하면 변주가 쉽다.
- **중재 모듈**: 갈등 조정용 중립 정거장에는 필수로 데이터 보관소와 공개 회의 공간을 넣는다.

## 3. 캐릭터 설계 플로우
### 3.1 체크 포인트
- **소속 층위**: 황실/관제국, 프론티어, 중재 연합 중 어디에 속하는가?
- **능력**: 항법·공학·외교·전술 중 주력 2개를 표기한다.
- **이해관계**: 조차권, 게이트 안정성, 자치권 등 어떤 시스템을 지키거나 무너뜨리고자 하는가?
- **장비**: 브레이슬릿·조약 결정판·드론 등 SF 소품을 필수 배치한다.
- **관계**: AI/인간/기업 간 신뢰도(동맹/경쟁/중재)를 기록한다.

### 3.2 아키타입 예시
- **게이트 관리자**: 기술/정치 모두 관여, 시스템 취약점을 알고 있음.
- **프론티어 사절**: 자원 생존권, 용병단과 연계된 밀수 루트.
- **중재 외교관**: 협상 테이블 설계, 비밀 인질 또는 가족 보호 동기.
- **자율 AI 분석가**: 진실 공개 vs 기억 편집 사이 갈등.

## 4. 운용 루틴
1. 사건이 필요하면 해당 노드의 에너지/교역/군사 상태를 갱신한다.
2. 캐릭터를 배치할 때 "누구의 통과 권한을 흔드는가"를 먼저 정의한다.
3. 새 노드를 추가하면 항로, 중력, 정치 규약을 동시에 업데이트하고 연대표에 기록한다.
