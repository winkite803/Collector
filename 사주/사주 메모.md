# 6단계. 형(刑)·충(沖)·합(合)·해(害) – 이승연 사주 기준 전체 분석

---

## 🔴 ① 형(刑) – 긴장, 내면 억제, 감정 압박

### ✅ 발생 여부: **발생함**

|구조|작용|설명|
|---|---|---|
|午(오) – 午(오)|자형(自刑)|동일 지지 중복 → 감정 과잉, 자기 억제, 열정 폭주|

### 🧠 해석

- **정오(火)의 기운이 겹쳐서 감정적 에너지가 과잉**
    
- 외향적 성향, 표현력 강함
    
- 그러나 **자기비판적이고, 긴장·압박을 스스로에게 가함**
    
- 리더십은 있지만, **무리하거나 자신을 몰아붙이는 경향**
    

---

## 🔵 ② 충(沖) – 충돌, 갈등, 대립, 이동

### ✅ 발생 여부: **발생함**

|구조|작용|설명|
|---|---|---|
|子(자) – 午(오)|정충(正沖)|방위/시간/오행 모두 반대 → 극단적 충돌 작용|

※ 午는 시지(오전 11시~1시), 자는 일지(자정) → 정반대 방향

### 🧠 해석

- **내면 감정(일지 子)**과 **외적 활동력(시지 午)**이 부딪힘
    
- 감정과 행동이 따로 노는 경향, 불안정성, **결정 회피 vs 강행 사이의 충돌**
    
- 인간관계에서도 **친할수록 충돌하거나**, 말로 감정을 조절하기 어려움
    
- 인생에서 **중요한 이동·전환 운**을 자주 겪음
    

---

## 🟡 ③ 합(合) – 유대, 끌림, 조화

### ✅ 발생 여부: **발생함**

|구조|작용|설명|
|---|---|---|
|午(오) + 未(미)|방합(方合)|화(火) → 토(土) 상생 관계 + 방향 조화|

### 🧠 해석

- **추진력(午)**과 **안정적 사유(未)**의 조화
    
- 이 사주는 겉으로는 강하지만, 실제로는 **협업·팀워크 능력도 있음**
    
- 일을 혼자 밀어붙이기보다 **보완자와 함께할 때 성과 상승**
    
- 감정적 균형, 인간관계에서 **도움을 받는 구조**
    

---

## 🟣 ④ 해(害) – 감정 간섭, 오해, 내적 피로

### ✅ 발생 여부: **발생함**

|구조|작용|설명|
|---|---|---|
|子(자) – 未(미)|해(害) 작용|음양·계절·오행 어긋남 → 간접적 간섭, 감정적 부담|

### 🧠 해석

- **지지끼리의 충돌은 아니지만, 미묘한 스트레스와 감정 피로 발생**
    
- 겉으론 조용해 보여도, **정서적 거리감/지침**이 생기기 쉬움
    
- 특히 가까운 사람(가족, 연인, 동료)일수록 **심리적 피로 누적**될 수 있음
    
- 자기감정 통제가 강하나, **내면 피로가 많고 조절이 필요한 구조**

# 🔥 화(火) 계열

### 천간(火)

1. 병화(丙火, 양화) → 태양, 가장 강력한 화.
    
2. 정화(丁火, 음화) → 등불·작은 불, 섬세하고 약하지만 조정 능력.
    

### 지지(火)

1. 오화(午火) → 여름 정오, 화의 제왕지 → **가장 강한 화**.
    
2. 사화(巳火) → 초여름, 불의 시작, 강하되 午보다는 약함.
    
3. 인목(寅木) → 목 속 지장간에 병화(丙火) 있음 → 화를 돕는 보조.
    
4. 신금(申金) → 지장간에 병화(丙火) 있음 → 미약한 불씨.  
    👉 **정리: 오화 > 사화 > 인목 > 신금**

# 💧 수(水) 계열

### 천간(水)

1. 임수(壬水, 양수) → 큰 바다, 가장 강력한 수.
    
2. 계수(癸水, 음수) → 이슬·가랑비, 섬세하고 약함.
    

### 지지(水)

1. 자수(子水) → 겨울 정점, 수의 제왕지 → **가장 강한 수**.
    
2. 해수(亥水) → 늦가을~초겨울, 자수를 돕는 강한 수.
    
3. 신금(申金) → 지장간에 임수(壬水).
    
4. 진토(辰土) → 지장간에 계수(癸水).  
    👉 **정리: 자수 > 해수 > 신금 > 진토**
    

---

# 🌳 목(木) 계열

### 천간(木)

1. 갑목(甲木, 양목) → 큰 나무, 줄기·뿌리, 가장 강한 목.
    
2. 을목(乙木, 음목) → 작은 풀, 유연하나 약함.
    

### 지지(木)

1. 인목(寅木) → 봄의 시작, 목의 제왕지 → **가장 강한 목**.
    
2. 묘목(卯木) → 봄의 절정, 순수 목 기운, 인목보다 한 수 아래.
    
3. 해수(亥水) → 지장간에 갑목(甲木).
    
4. 미토(未土) → 지장간에 을목(乙木).  
    👉 **정리: 인목 > 묘목 > 해수 > 미토**

# 🪨 금(金) 계열

### 천간(金)

1. 경금(庚金, 양금) → 큰 쇠, 바위, 강력.
    
2. 신금(辛金, 음금) → 작은 쇠, 장신구, 세밀하나 약함.
    

### 지지(金)

1. 유금(酉金) → 가을 정점, 금의 제왕지 → **가장 강한 금**.
    
2. 신금(申金) → 금의 시작, 유금보다 한 수 아래.
    
3. 술토(戌土) → 지장간에 신금(辛金).
    
4. 축토(丑土) → 지장간에 계수·신금 있음 → 금 보조.  
    👉 **정리: 유금 > 신금 > 술토 > 축토**

# ⛰ 토(土) 계열

### 천간(土)

1. 무토(戊土, 양토) → 큰 산, 단단함, 강한 토.
    
2. 기토(己土, 음토) → 밭흙, 부드럽지만 약함.
    

### 지지(土)

1. 진토(辰土) → 용, 봄의 토, 습토.
    
2. 술토(戌土) → 개, 가을의 토, 건토.
    
3. 축토(丑土) → 겨울의 토, 한랭한 토.
    
4. 미토(未土) → 여름의 토, 불(火)을 품은 습토.  
    👉 **정리: 진토 > 술토 > 축토 > 미토**

천간 양기 순서
- **갑목(甲木)**: 가장 순수한 양기.
    
- **병화(丙火)**: 전면적 양기, 다만 변동성 있음.
    
- **무토(戊土)**: 큰 산, 안정된 양.
    
- **정화(丁火)**: 작은 불이지만 꺼지지 않고 지속되는 양성 → 일부 양간보다 양적일 수 있음.
    
- **임수(壬水)**: 큰물, 외향 확산 + 깊은 음성 → 중간.
    
- **을목(乙木)**: 풀, 음간이지만 성장·확산성이 양적.
    
- **경금(庚金)**: 강철, 겉은 양적이지만 본질은 차갑고 응축적(음).
    
- **기토(己土)**: 밭흙, 포용적이지만 생명력 내포 → 음이 우세.
    
- **신금(辛金)**: 보석, 빛나지만 본질은 응축·내향.
    
- **계수(癸水)**: 이슬·안개, 가장 은밀·음적.
