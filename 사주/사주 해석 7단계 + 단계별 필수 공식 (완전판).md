## ✅ 1단계. 천간·지지 분리 (四柱八字, 사주팔자 구성)

- 생년월일시 → 각 기둥을 **천간(天干, 하늘 기운) + 지지(地支, 땅 기운)**으로 나누어 **총 8글자 구성**
    
- 각 기둥: 년주 / 월주 / 일주 / 시주

## ✅ 4단계. 십성(十星) 계산 공식 + 명칭 해설

### ◾ 공식: 일간 기준 **오행 생극관계 + 음양 조합**으로 결정

| 관계    | 음양 같음      | 음양 다름      | 십성 명칭 |
| ----- | ---------- | ---------- | ----- |
| 나를 생함 | 정인(正印, 정인) | 편인(偏印, 편인) |       |
| 내가 생함 | 식신(食神, 식신) | 상관(傷官, 상관) |       |
| 나와 같음 | 비견(比肩, 비견) | 겁재(劫財, 겁재) |       |
| 나를 극함 | 정관(正官, 정관) | 편관(偏官, 편관) |       |
| 내가 극함 | 정재(正財, 정재) | 편재(偏財, 편재) |       |

|십성|한글|역할|성향 키워드|

|傷官|상관|내가 낳는 날카로운 기운|창의성, 개성, 반항, 논리, 직설|
|比肩|비견|나와 같은 기운|자존감, 자립심, 독립성, 경쟁력|
|劫財|겁재|나와 같은데 부딪힘|리더 기질, 강한 추진, 파격적 관계성|
|正官|정관|나를 제어하는 기운|책임감, 공정성, 조직 순응, 윗사람 존중|

|偏財|편재|내가 자유롭게 쓰는 기운|활동성, 개방성, 외향적, 비즈니스 능력|
