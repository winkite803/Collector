# 원진살

| 이름    | 조합              | 설명(자연물 비유)                                | 관계(사람 관계 느낌)             |
| ----- | --------------- | ----------------------------------------- | ------------------------ |
| 자미 원진 | 자수(子水) + 미토(未土) | 차가운 물이 따뜻한 흙에 스며들지만 탁해져 흐르지 못한다           | 가까워도 답답하고 오해가 쌓이는 관계     |
| 축오 원진 | 축토(丑土) + 오화(午火) | 눅눅한 흙이 뜨거운 불길을 막아 불도 흙도 답답하다              | 열정과 현실이 맞부딪혀 불만이 생기는 관계  |
| 인사 원진 | 인목(寅木) + 사화(巳火) | 큰 나무가 불길에 닿아 활활 타지만, 불길은 나무에 갇혀 더 번지지 못한다 | 서로 끌리지만 상처와 불만이 남는 관계    |
| 묘신 원진 | 묘목(卯木) + 신금(申金) | 연약한 풀과 덩굴이 단단한 금속에 베이며 자라지 못한다            | 한쪽은 억압당하고, 다른 쪽은 불편한 관계  |
| 진해 원진 | 진토(辰土) + 해수(亥水) | 흙 속으로 물이 흘러들지만 흙은 질척이고 물은 탁해진다            | 서로 도움을 주려 하지만 피로와 오해만 쌓임 |
| 사유 원진 | 사화(巳火) + 유금(酉金) | 불꽃이 쇠에 부딪혀 튀지만 쇠는 달궈지지 않고 불만 소모된다         | 열정이 허공으로 흩어지고 냉담함만 남는 관계 |

# 귀문관살

| 이름             | 조합          | 설명                                        | 관계(사람 관계 느낌)            |
| -------------- | ----------- | ----------------------------------------- | ----------------------- |
| **자유귀문(子酉鬼門)** | 자(子) + 유(酉) | 예민하고 영적 감수성 강하며 독특한 개성. 고립·공주병 기질로 보이기도 함 | 차갑고 단절적이지만 직관·감수성 풍부    |
| **축오귀문(丑午鬼門)** | 축(丑) + 오(午) | 성정이 불같이 폭발하고 욱하는 성향. 충동적이지만 추진력 강함        | 겉으론 열정적, 속으론 균열과 갈등     |
| **인미귀문(寅未鬼門)** | 인(寅) + 미(未) | 철학적·사색적·은둔적 성향. 애늙은이 같은 느낌                | 외로움·고독 속에서 깊은 사유, 내면 성장 |
| **묘신귀문(卯申鬼門)** | 묘(卯) + 신(申) | 도화살 기운, 잘난 체·외향적 인기. 내면은 불안정              | 겉은 매력적이지만 속은 흔들리고 상처 많음 |
| **진해귀문(辰亥鬼門)** | 진(辰) + 해(亥) | 예민하고 섬세, 콤플렉스가 많음. 예술성·섬세함으로 승화 가능        | 섬세·복잡, 내면 갈등을 창작력으로 바꿈  |
| **사술귀문(巳戌鬼門)** | 사(巳) + 술(戌) | 음흉·이중적·의심 많음. 전략가적 면모로도 발현                | 관계 속 불신, 그러나 통찰·계산에 능함  |
