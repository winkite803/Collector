# 오행

|오행(五行)|자연 상징|계절 / 방향|색|성격적 이미지|
|---|---|---|---|---|
|목(木)|나무, 성장|봄 / 동쪽|청록|성장, 창조, 확장, 곧음|
|화(火)|불, 열|여름 / 남쪽|붉음|열정, 활동, 추진력, 따뜻함|
|토(土)|흙, 땅|환절기 / 중앙|황색, 갈색|안정, 균형, 신뢰, 중재|
|금(金)|쇠, 금속|가을 / 서쪽|흰색, 금속색|결단력, 강인함, 규율, 날카로움|
|수(水)|물|겨울 / 북쪽|검정, 짙은 청색|지혜, 유연함, 깊음, 내성|

# 오행 상생표

|관계|설명|비유|
|---|---|---|
|목(木) → 화(火)|나무가 불을 키운다|땔감이 불을 만든다|
|화(火) → 토(土)|불이 재(흙)를 만든다|불이 꺼지고 흙으로 돌아간다|
|토(土) → 금(金)|흙 속에서 금속이 생긴다|광물이 땅속에서 나온다|
|금(金) → 수(水)|쇠가 차갑게 응축되어 물을 만든다|금속 표면의 응결수|
|수(水) → 목(木)|물이 나무를 자라게 한다|비가 내려 나무가 큰다|

# 오행 상극표

| 관계          | 설명             | 비유            |
| ----------- | -------------- | ------------- |
| 목(木) → 토(土) | 나무 뿌리가 흙을 파헤친다 | 나무가 흙을 뚫고 자란다 |
| 토(土) → 수(水) | 흙이 물길을 막는다     | 둑이 강물을 막는다    |
| 수(水) → 화(火) | 물이 불을 꺼뜨린다     | 비가 불을 끈다      |
| 화(火) → 금(金) | 불이 쇠를 녹인다      | 제련소에서 쇠를 녹인다  |
| 금(金) → 목(木) | 쇠가 나무를 자른다     | 도끼가 나무를 벤다    |
