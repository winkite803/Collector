# 지장간

|지지(地支)|지장간(地藏干)|설명|
|---|---|---|
|자수(子水)|임수(壬水) · 계수(癸水)|겨울 한밤의 물, 큰 강물(壬水)과 샘물·이슬(癸水) → 깊음·지혜·내면|
|축토(丑土)|기토(己土) · 계수(癸水) · 신금(辛金)|겨울 얼어붙은 땅 속, 습한 흙(己土), 얼음 같은 물(癸水), 감춰진 금속(辛金) → 저장·응축|
|인목(寅木)|갑목(甲木) · 병화(丙火) · 무토(戊土)|봄 산림, 큰 나무(甲木), 숨은 불씨(丙火), 땅의 힘(戊土) → 성장·발전|
|묘목(卯木)|갑목(甲木) · 을목(乙木)|봄 들판, 큰 나무(甲木)와 풀·꽃(乙木) → 확장·유연함|
|진토(辰土)|무토(戊土) · 을목(乙木) · 계수(癸水)|봄 늪지, 습한 흙(戊土), 풀·잡초(乙木), 수분(癸水) → 교착·저장|
|사화(巳火)|병화(丙火) · 무토(戊土) · 경금(庚金)|초여름 불길, 큰 불(丙火), 불에 달궈진 흙(戊土), 단련된 쇠(庚金) → 발산·단련|
|오화(午火)|병화(丙火) · 정화(丁火) · 기토(己土)|여름 태양과 불꽃, 큰 불(丙火), 등불 같은 불(丁火), 뜨거운 땅(己土) → 활력·명랑|
|미토(未土)|기토(己土) · 을목(乙木) · 정화(丁火)|여름 들판의 흙(己土), 잡초(乙木), 불씨(丁火) → 포용·중재|
|신금(申金)|경금(庚金) · 임수(壬水) · 무토(戊土)|가을 광석, 큰 쇠(庚金), 그 속의 물기(壬水), 흙(戊土) → 강인함·잠재력|
|유금(酉金)|경금(庚金) · 신금(辛金)|가을 맑은 금속, 큰 쇠(庚金)와 보석·작은 쇠(辛金) → 결단·정제|
|술토(戌土)|무토(戊土) · 신금(辛金) · 정화(丁火)|가을 흙(戊土), 땅속 금속(辛金), 불씨(丁火) → 저장·에너지|
|해수(亥水)|무토(戊土) · 갑목(甲木) · 임수(壬水)|겨울 큰 강물(壬水), 씨앗의 나무(甲木), 차가운 흙(戊土) → 포용·새싹 준비|


# 지장간 암합

| 이름    | 조합                                    | 설명(비유)                                                                            | 효과                         |
| ----- | ------------------------------------- | --------------------------------------------------------------------------------- | -------------------------- |
| 축자 암합 | 축토(丑土) → 속 신금(辛金) + 자수(子水) → 속 계수(癸水) | 눅눅하고 얼어붙은 땅(축토) 속 쇠 성분(신금), 얼어붙은 강(자수) 속 녹아 나온 물줄기(계수)가 만나, 겉은 막혀 있지만 속은 쇠가 씻겨 빛남 | 금생수(金生水) 은밀한 흐름 → 자원 보완·정리 |
| 인해 암합 | 인목(寅木) → 속 갑목(甲木) + 해수(亥水) → 속 임수(壬水) | 큰 숲(인목)의 뿌리(갑목)가 바다(해수) 속 깊은 물줄기(임수)를 머금어 겉은 고요하지만 속은 자람                          | 수생목(水生木) 은밀한 성장 → 기반 강화    |
| 묘술 암합 | 묘목(卯木) → 속 을목(乙木) + 술토(戌土) → 속 신금(辛金) | 풀과 덩굴(묘목·을목)이 언덕(술토) 속 쇠 성분(신금)에 걸려 잘리고 교정됨                                       | 금극목(金剋木) 은밀한 교정 → 조율·긴장    |
| 사신 암합 | 사화(巳火) → 속 병화(丙火) + 신(申) → 속 경금(庚金)   | 불길(사화) 속 불빛(병화)이 바위산(신) 속 광석(경금)을 달구어 단단히 벼려냄                                     | 화극금(火剋金) 은밀한 단련 → 강화·성장    |
| 오미 암합 | 오화(午火) → 속 정화(丁火) + 미토(未土) → 속 을목(乙木) | 태양 불빛(오화) 속 등불(정화)이, 언덕(미토) 속 나뭇가지(을목)를 연료 삼아 꾸준히 활기를 이어감                         | 목생화(木生火) 은밀한 연료 → 지속·활력    |
| 유진 암합 | 유금(酉金) → 속 신금(辛金) + 진토(辰土) → 속 을목(乙木) | 가을의 쇠덩이(유금) 속 칼날(신금)이, 촉촉한 논밭(진토) 속 덩굴(을목)을 잘라내며 다듬음                              | 금극목(金剋木) 은밀한 연마 → 품질·정밀    |
| 해오 암합 | 해수(亥水) → 속 임수(壬水) + 오화(午火) → 속 정화(丁火) | 큰 바다(해수) 속 깊은 물기운(임수)과 태양(오화) 속 불씨(정화)가 만나, 수증기·안개로 변환됨                           | 수극화(水剋火) 은밀한 전환 → 변화·균형    |
